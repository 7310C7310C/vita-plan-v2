# 复活计划乐队 · 在线歌谱

> 线上：<https://kcan.cc/>

复活计划乐队的在线歌谱库：查本周歌曲、分类谱与不同版本，支持播放、选段和标注。

## 找歌
- **本周歌曲**：按适用日期列出本周曲目。
- **分类**：进堂咏、垂怜曲、光荣颂、答唱咏（朱健仁）、福音前欢呼、奉献咏、天主经、领主咏、礼成咏、圣诞、圣神、备用、其他。
- **答唱咏**：按通用、甲年、乙年、丙年分组。
- **搜索**：歌名、编号或分类；英文界面可用英文分类名。
- **收藏与最近查看**：右上角面板；最近 10 条，收藏不限，均只存本机。

## 看谱
- 歌曲默认可播放；点音符试听。没有可播放谱的歌自动显示图片谱。
- 可播放谱点顶栏「图片谱」对照原图，再点「返回」回播放谱；只有图片的歌直接显示图片谱。
- **版本**：原谱、贝司、吉他、备选；只显示已上传版本，切换后网址同步，方便分享。
- **版面**：JSON 谱默认不自动换行，按乐句换行显示；需要按屏幕宽度换行时点顶栏「自动换行」。
- 顶栏另有收藏、菜单、播放/暂停与关闭。

## 播放
- 点任意音符从该处播放；再点会从新位置重开，不会叠音。
- 「菜单」可调：
  - 声部 S/A/T/B、节拍器、速度、音量；
  - 音色 112 种（14 组），进谱后预载当前音色；首次使用需联网，取样音源未就绪时起播会稍候（每次载入从第一次播放起总共最多约 3 秒，之后直接起播），超时则本次播放先用合成音，不会中途切换音色；
  - 变调夹默认 0 品，手动选择；谱面和弦自动转成等价指法并显示 Capo 品数；播放音高不变；选择按曲保存；
  - 字号、跟随播放、夜间模式、简繁切换、重置。
- **反复与选段**：支持谱面反复；拖动选段循环。反复第二遍时点区间内继续当前遍；停止或自然播完后再点，从第一遍开始。
- 关闭查看器、切歌或切到图片谱会停止播放。

## 标注与涂改
- **可播放谱**：底栏「标注」；点音符画圈，拖动框选可输入文字；点已有标注可修改或清空，点右上角「×」删除；支持保存、清空、橡皮擦、撤销/重做。
- **图片谱**：底栏「涂改」；用手指或鼠标画线；支持保存涂改、清空、橡皮擦、撤销/重做。
- 标注与涂改都只存当前浏览器、按歌曲保存；清理网站数据会丢失。

## 手机与键盘
- **手机**：上下滚动看谱；点音符播放；底栏可切上一首/下一首、切版本、标注/涂改、开关自动换行。
- **键盘**：`Space` 播放/暂停；`Esc` 停止；`Ctrl/Cmd + A` 选中整首循环。

## 界面
- 右上角「中/En」切换界面；英文标题为 **Vita Plan**，分类名会翻译；歌曲标题、歌词与标注不自动翻译。
- 为确保曲目与曲谱始终最新，当前不做自动缓存；每次打开都从网络读取最新数据。
- 音色采样首次使用需联网；简繁转换需联网；字体使用设备自带字体。

## 隐私与限制
- 无需注册或登录；收藏、最近查看、标注、播放设置与语言偏好只存本机，不会上传。
- 乐谱与图片为公开内容，请勿在标注中填写敏感信息。
- 建议使用较新的 Chrome、Edge、Safari 或 Firefox。
- 部分歌曲只有图片谱，不能播放；未上传的版本不显示。
- 取样音源若完全卡住（不是失败），页面不会无限等它；本次播放会先用合成音，需重新整理页面才会重新尝试载入。
- 约 320px 窄屏下，底栏工具略挤。
