# 复活计划乐队 · 在线歌谱

> 复活计划乐队的在线歌谱库。打开网页即可查看本周歌曲、分类歌谱与不同版本，适合排练前查谱、排练中翻谱和演出前复习。
>
> 线上：<https://kcan.cc/>

## 三步开始

1. 打开网址，进入歌谱首页。
2. 点「本周歌曲」，或从分类中选歌；也可以直接搜索歌名、编号或分类。
3. 点开歌曲看谱；需要看原始图片时，点顶栏的「图片谱」。

## 首页与查找

- **本周歌曲**：显示本周排练或礼仪使用的歌曲，并标注适用日期。
- **分类浏览**：进堂咏、垂怜曲、光荣颂、答唱咏（朱健仁）、福音前欢呼、奉献咏、天主经、领主咏、礼成咏、圣诞、圣神、备用、其他。
- **答唱咏**：按通用、甲年、乙年、丙年分组，方便按礼仪年查找。
- **搜索**：支持歌名、歌曲编号和分类；英文界面下也可用英文分类名搜索。
- **收藏与最近查看**：右上角面板可查看；最近最多 10 条，收藏数量不限。记录只保存在当前浏览器。

## 看谱

- 歌曲默认显示**可播放的乐谱**，可以直接点音符试听。
- 点顶栏「**图片谱**」可切换到原始图片谱；看完点「**返回**」回到可播放乐谱。
- 没有可播放乐谱的歌曲会自动显示图片谱。
- **版本**：每首歌可有原谱、贝司、吉他、备选等版本，只显示已上传的版本；切换后网页地址会同步，方便分享。
- 顶栏另有收藏、菜单、播放/暂停与关闭按钮；手机上按钮会自动换行，避免挤在一起。

## 播放

- 点谱面上的**任意音符**，从该处开始播放。
- 顶栏的播放/暂停图标可随时控制；再次点音符会从新位置重新开始，不会叠音。
- 打开「菜单」可调整：
  - **声部**：单独开关 S / A / T / B，或一次全开；
  - **节拍器**：播放时听到拍点；
  - **速度**：拖动调整快慢；
  - **音量**；
  - **音色**：112 种乐器（14 组），首次使用需联网加载；选择后会提示加载中，加载完成前先用合成音。
  - **变调夹（Capo）**：默认 0 品，不会按图片或曲目自动设置；乐手自行选择夹几品，谱面和弦会自动转成对应的等价指法和弦，并在谱面上方显示 Capo 品数；实际播放音高不变。你的选择会按曲保存。
  - **字号**：调整谱面大小；
  - **显示**：跟随播放、夜间模式、简繁切换；
  - **重置**：恢复默认设置。
- **反复与选段**：支持谱面反复记号；拖动选择一段可循环播放。反复第二遍时点区间内其他位置会继续当前遍；停止或自然播完后再点区间内，会从第一遍重新开始。
- 关闭查看器、切歌或切到图片谱时会停止播放。

## 标注

- 在底栏点「**标注**」进入标注模式；进入后会暂停播放，避免误触。
- **点单个音符**会画一个红圈；**拖动框选**多个音符会用圆角矩形圈住，并可输入文字。
- 点已有的红圈/文字可修改文字或清空；点圈右上角的「×」可删除该处标注。
- 标注工具：
  - **保存**：保存到本机并退出标注模式；
  - **清空**：清除本曲全部标注；
  - **橡皮擦**：打开后，手指或鼠标划过的标注会被清除；再点一次关闭；
  - **撤销 / 重做**：回退或恢复操作。
- 标注文字使用半透明底色，尽量不挡住音符和歌词。
- 标注只保存在当前浏览器，按歌曲分开保存；清理网站数据后会丢失。

## 手机与键盘

- **手机**：上下滚动看谱；点音符播放；底栏可切上一首/下一首、切版本、进标注、开关自动换行。
- **键盘**：
  - `Space`：播放 / 暂停；
  - `Esc`：停止；
  - `Ctrl/Cmd + A`：选中整首循环。

## 中英文界面

- 右上角「中/En」可切换界面语言，选择会被记住。
- 英文界面下标题显示为 **Vita Plan**，分类名也会翻译。
- 歌曲标题、歌词与标注文字以录入内容为准，不随界面语言自动翻译。

## 离线使用

- 首次进入后，应用与全部可播放乐谱会在后台缓存；之后断网也能打开已缓存的乐谱与合成音。
- **图片谱不保证离线**，只在浏览时按浏览器缓存策略保存。
- **音色采样**会按使用过的音色缓存在本机；没缓存过的音色离线时可能退回合成音。
- **简繁转换**需要联网；离线时无法切换。
- 字体使用设备自带字体，不额外下载。
- 离线缓存只保存在当前浏览器、当前网址；清理网站数据、无痕模式或更换设备后会失效。

## 隐私

- 本站无需注册或登录。
- 收藏、最近查看、标注、播放设置与语言偏好只保存在本机，不会上传服务器。
- 乐谱与图片为公开内容，请勿在标注中填写敏感信息。

## 常见问题

- **为什么有的歌不能播放？** 该歌目前只有图片谱，尚未制作可播放乐谱。
- **为什么某个版本不见了？** 该版本尚未上传，只显示已上传的版本。
- **为什么换设备后收藏/标注不见了？** 这些内容只存在原设备的浏览器里，不会同步。
- **为什么离线时没有声音？** 合成音可以离线；音色采样需要事先联网使用过才会缓存。
- **为什么字体和别人看到的不同？** 本站使用设备系统字体，不同系统显示会略有差异。
- **页面太宽/太窄？** 可在菜单调整字号；手机窄屏下按钮会自动换行。

## 兼容与限制

- 建议使用较新的 Chrome、Edge、Safari 或 Firefox。
- 极窄屏（约 320px）下，图片谱底部的涂改工具较多，可能略显拥挤。
- 部分歌曲只有图片谱，不能使用播放器与标注。
